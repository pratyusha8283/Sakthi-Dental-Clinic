# 🦷 Sakthi Dental Clinic Website

A modern, responsive and user-friendly website designed for Sakthi Dental Clinic, Hosur.

## 📌 About the Project

This project was developed as an Intermediate Level Full Stack Developer Internship task. The website is designed to provide patients and families with clear information about the clinic, its dental treatments, facilities, doctors and contact details.

## ✨ Features

- Responsive design for desktop, tablet and mobile
- Modern and clean healthcare-focused UI
- Home page with hero section and call-to-action
- About Us page
- Dental Treatments page
- Frequently Asked Questions (FAQs)
- Patient Testimonials
- Clinic Facilities and Amenities
- Contact form with validation
- Privacy Policy page
- Easy navigation between pages
- SEO-friendly structure
- Optimized images and assets

## 🦷 Treatments Covered

The website presents information about various dental services, including:

- Teeth Cleaning & Scaling
- Tooth Filling
- Tooth Extraction
- Artificial Complete Denture
- Dental Implants
- Laser Dentistry
- Root Canal Therapy
- Wisdom Tooth Extraction
- Fixed Partial Denture
- Teeth Whitening
- Veneers
- Pediatric Dentistry
- Flap Surgery
- Orthodontic Braces
- Clear Aligners
